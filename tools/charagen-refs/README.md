# 劇情角色的參考圖

角色產生器（docs/portrait-design.md）做外觀時參考的圖，檔名＝`<角色 id>_<編號>.jpg`（id＝遊戲的說話者，`mech_cordon_charagen/js/roster.js`）。

2026-11-11 使用者決定放進版本庫，換電腦時直接 pull 就有。這些是別人的作品（有的帶簽名與浮水印）：**只取方向（髮型、配色、服裝的感覺），不照原圖複製**；產生的角色要改成遊戲自己的設計（陣營色、配件、和劇情有關的東西），簽名、浮水印、文字一律不要出現。

做某個角色時，在角色產生器的「外觀」分頁上傳這個角色的參考圖。新增參考圖照同樣的檔名放進來並補這張表。

**男角共用的方向**（`male_1.jpg`～`male_12.jpg`，2026-11-12 使用者提供）：**男角一律看起來年輕**（二十到三十出頭的動漫臉，不畫皺紋、大鬍子、禿頭），劇本裡的年紀只表現在個性、髮色（銀灰）、傷疤與服裝上。取的方向：修長的身材、蓬鬆有層次的短髮或低馬尾、機能街頭風（高領、綁帶、扣具、工裝褲、無指手套、厚底鞋）、黑白為底＋一個強調色。
