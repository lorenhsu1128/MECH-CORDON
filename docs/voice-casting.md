# 語音 v3：選角與每個角色的 LoRA

2026-11-14 使用者：「目前的語音同角色的聲音會變」，要求用 **LoRA（方法 C）** 鎖住每個角色的聲音，並「仔細分析並參考絕區零各角色的配音以及日文超時空要塞F 的角色配音，重製所有角色的語音」，內容由 Claude 決定。

## 為什麼聲音會變（語音 v2 的問題）

量測（`microsoft/wavlm-base-plus-sv` 的說話者向量，和參考音的餘弦相似度）：霍斯特現有 40 句平均 0.886、最低 0.792；不同人（薩奇）0.51。原因：

1. **語氣指示把音色拉走**：每句是「參考音＋括號裡的語氣指示」，VoxCPM2 把括號裡的文字也當成聲音設計；語音 v2 照表情加了強烈的語氣（生氣、大笑、哭腔），音色跟著飄。
2. **挑 take 只看唸得對不對**（Whisper），沒有看像不像本人。
3. 中文與日文是兩個不同設計的聲音（同一個角色換語言就換人）。

## 做法（`scripts/voice-lora.py`）

- **一個角色一個聲音**：中文與日文共用（參考音用日文的句子設計，日本動畫配音的質感；中文以同一個參考音克隆）。選角在 `scripts/voice_cast.json`。
- **每個聲音訓練一個 LoRA**（VoxCPM 2.0.3 的 LoRA 微調，r 32、LM 與 DiT）：訓練資料＝用新的參考音克隆角色自己的台詞（中文、日文各約 50 句，情緒盡量分散；台詞少的補通用句），每句 3 次，**只留唸對（轉寫相似度 ≥ 0.8）而且聲紋最像參考音的那一次**，再去掉聲紋最不像的 15%。訓練文字包含語氣指示，所以 LoRA 學到「生氣時也還是這個人」。
- **產生全部台詞**：`voice-gen.py --v3` 載入該角色的 LoRA；挑 take 時唸對與聲紋一起算。
- LoRA、訓練資料、VoxCPM 的原始碼在 gitignore 的 `tools/voxcpm/`（每台電腦要重做時跑 `voice-lora.py`；產生的 mp3 照舊進 git）。

## 紀錄（2026-11-14～15）

### 做法的修正（照試做的結果）

1. **參考音要「克隆得穩」**（最重要）：只看唸對與音高挑出來的參考音，有些克隆出來就會飄；LoRA 學到的是這些句子的「平均」，結果偏成另一個人（芮恩：原本模型 0.829 → LoRA 0.709）。聲音設計加了 `--stable`：每個候選先當參考音克隆 2 句（中、日各 1），量和候選本身的聲紋相似度，分數＝唸對＋2×（穩定度−0.9）。重新設計後芮恩的 LoRA 0.918、WHITEOUT／UNDERTOW／VOLTA／KEEL 也從「LoRA 比較差」變成「LoRA 比較好」。同一批候選的穩定度可以從 0.77 到 0.95，差很多。
2. **訓練資料至少 5 分鐘、而且一致**：台詞少的角色（宿敵、僚機、敵兵）只有 2～3 分鐘時 LoRA 會變差（巴索、OXIDE）。通用句從 20 組加到 60 組（較長、情緒分散），每種語言湊到 60 句，再去掉聲紋最不像的 20% 與低於 0.85 的。
3. **訓練步數不是問題**：SLUICE 試 300 步（600 步的一半），只比 600 步好一點，仍不如原本模型。
4. **長句會讓顯示卡溢出**：一批 4 句時有 12.8 秒的句子會用滿 32 GB、溢到共用記憶體慢 2.5 倍；訓練時略過 11.5 秒以上的句子（`MAX_CLIP`）。產資料的程序沒放掉模型時訓練也會卡住，所以設計＋資料、訓練、比較各自一個程序。
5. **用不用 LoRA**（`voice-gen.py` 的 `lora_ok`，照 `eval.json`）：LoRA 的聲紋平均不低於原本模型 0.01，而且最低值不低於 0.03——或平均高 0.03 以上（比較只有 16 句，最低值常被單一句拉低）。31 個聲音 29 個用 LoRA；SLUICE、旁白用原本的模型（新參考音本身就很穩）。
6. **日文的讀音**：讀音表（`lines-ja.json` 的 `@yomi`）開頭是「は」的會被當成助詞唸「わ」（方舟→わこぶね），改成片假名（ハコブネ、ハカセ…）；英文名字（SOVEREIGN、KILN、KEEL、HEARTH、BASALT、SALAMANDER、ANVIL、COLOSSUS、ECHO）補上唸法。日文報告裡「唸對」偏低的多半是 Whisper 把同音詞寫成別的漢字（降下→効果、管制→完成、好機→後期），不是唸錯。
7. **COUNTDOWN**：日文的聲音設計 18 個候選都是 200 Hz 以上（描述的「亢奮、大笑」把音高推上去），和語音 v2 一樣改用中文版的參考音（`ref/countdown.flac`，122 Hz）。男角的描述寫「男中音」（OXIDE、SPIRE、IGUAZU、SPECIMEN），否則「清亮、輕快」常常變成高音。

### 重做的指令

```bash
# 一個聲音：設計（--stable 看克隆穩定度）＋資料、訓練、比較各自一個程序（LoRA 等在 gitignore 的 tools/voxcpm/）
python scripts/voice-lora.py --voice=<聲音> --steps=design,data --stable
python scripts/voice-lora.py --voice=<聲音> --steps=train
python scripts/voice-lora.py --voice=<聲音> --steps=eval
# 全部台詞（每句 3 次）；中途當掉用 --resume 接著做；報告裡偏低的句子 --retry 多產生 2 次重挑
python scripts/voice-gen.py --v3 --lang=zh --takes=3 --force
python scripts/voice-gen.py --v3 --lang=ja --takes=3 --force
python scripts/voice-gen.py --v3 --lang=ja --takes=3 --retry
```

Python 用 conda 環境 `rubicon-voice` 的完整路徑（Git Bash 的 `python` 是 Windows 商店的空殼，執行了也不會有任何動作），環境變數 `TORCHINDUCTOR_USE_STATIC_CUDA_LAUNCHER=0`、`HF_HUB_DISABLE_XET=1`、`PYTHONIOENCODING=utf-8`。每個聲音約 25 分鐘（設計 2、資料 8、訓練 11、比較 4），全部台詞中文、日文各約 3.5 小時（RTX 5090）。
