# 機獸出擊的劇本（文案與語音）

2026-11-21 起草，**等使用者審閱**。範圍：第 1～7 章的機獸出擊 `c<章>b`、獅型亂入、第 8 章的機獸機庫、載入提示。
之前的簡報與通訊是佔位用的範本句（`docs/beast-design.md` 的「劇情先不寫」），這份取代它們。

## 使用者的決定（2026-11-21）

1. 來歷用方案 A：**封鎖線的清道夫**，獅型是**回收者**。
2. **第 1 周目就講清楚**機獸是什麼（照章節逐步說完，第 7 章全部交代）。第 3 周目只多 ECHO 自己和牠們的關係。
3. 每隻要有**正式代號**（Claude 取）。
4. c6b 的委託方改成**薩奇**。
5. 第 8 章做**機獸機庫**。

## 一、設定（作者用）

- **清掃單位**（日文：掃除ユニット）：封鎖線協定的簽署者造的自律機，平時收在方舟的機獸機庫，一個籠位一隻，共八隻。
- **任務是「收尾」**：每個週期，牠們跟在你後面，把會讓人起疑的東西掃平，包括紀錄、設施、目擊者和調查隊。所以每一章的事情辦完，牠們才出現。
  - 對得上簡報「四周的東西全被它掃平了」、第 2 周目 c1x「消失的調查隊」。
- **為什麼打你**：第 1 周目的說法是你看到了太多，也在清除範圍裡。
  - 第 3 周目 ECHO 才說出真相：牠們的武器從來沒有對準你的駕駛艙。命令要牠們「保全鑰匙、清除其他一切」，你的機體算「其他」，你本人不算。
- **REGENT（獅型）＝回收者**：只在清掃單位失敗時出動，把殘骸與核心帶回方舟，不讓任何勢力拿去研究。
  - 平常沒人見過牠，所以殘骸總是「已經不見了」。
  - 亂入時咬死受傷的那一隻，就是在回收。
  - 牠打你，是因為你擋在回收作業的路上。
- **每個週期方舟會重新造出一批**，所以第 2、3 周目還會遇到同一隻。
- **各委託方知道多少**（和主線一致）：
  - 霍斯特：知道。卡斯特隆的合約裡有一條「不得干涉清掃單位」。
  - 薩奇：知道，一直想要樣本。
  - 派克：不知道，只看得到錢和技術。
  - 諾拉：不知道，只看得到被掃平的營地和名字。
- **ECHO 和牠們的關係**（只在第 3 周目說）：派遣命令經過軌道站的管制系統，也就是她。她看得到每一道命令，以前一次都沒擋過。

## 二、格式說明

- **說話者**：`echo`、`castron`＝霍斯特、`aetheric`＝薩奇、`veerwell`＝派克、`sancta`＝諾拉、`mira`＝米拉。
- **事件**：沿用現有的 sortieStart／segStart／bossHalf／sortieEnd／fail／raidIn／raidGo。【新】是要新加的：
  - `beastPart`：第一個外掛武器被打壞。
  - `bossP3`：進入最後型態。
  - `raidBite`：REGENT 咬死原本的機獸。
  - `raidWon`：打倒 REGENT。
  - 新條件：`raid`（REGENT 在場）、`raidWon`（存檔裡打倒過 REGENT）。
- **周目**：〔周目 2〕〔周目 3〕＝只在那個周目播。沒標的每個周目都播。
- **簡報**：簡報的語音情境是 brief（當面說），通訊是 comm。

### c1b　礦坑最深處 — UNDERTAKER（維爾威／派克）

**簡報**（派克）

1. 好消息，礦坑清完了。壞消息，有東西在你後面又把它清了一遍。
2. 我們的探勘隊在最深的那層失聯。最後一張影像只有一條拖痕——很寬，八條腿。
3. 無線電截到它在廣播一串識別碼：UNDERTAKER。不是任何一家公司的編號。
4. 它會鑽地，地上出現紅圈就跑。用實彈打，能量打不太動；螯上的切割砲跟背上的迫擊筒可以拆。
5. 時間就是錢，傭兵。它每在我的礦道裡挖一公尺，都是我的錢。

### c5b　洋上都市上空 — SHRIKE（卡斯特隆／霍斯特）

**簡報**（霍斯特）

1. 電纜塔上掛著東西。……是機甲，被插在塔尖上。我們的，還有別家的。
2. 那是 SHRIKE。清掃單位，會飛的那一台。
3. 我老實說：清掃單位是簽署者放出來的，專門把會讓人起疑的東西掃掉。卡斯特隆的合約裡有一條——不得干涉清掃單位。
4. ……我今天違約了。它平常在天上盤旋，俯衝下來之前地上會有路線；打到失衡它會掉下來。用爆發的打，能量不太有用。翼下的導彈和腹下的炸彈艙可以拆。
5. 合約就是合約。可是有些合約，簽的人不該是我。

## 六、載入提示（只有文字，沒有語音）

每隻兩則，寫進 `data/tips.js`，第一次遇到之後才出現：

- **UNDERTAKER**：
  - 地上的紅圈是它要鑽出來的地方，先離開再回頭打；尾刺刺空就是破綻。
  - 實彈打得動、能量打不太動。螯上的切割砲和背上的迫擊筒可以拆。
- **SILT**：
  - 背甲吃實彈，用爆發的打；咬合很快，看到它張嘴就橫移。
  - 縮殼轉起來就跳開，轉完它會暈。
- **RIME**：
  - 雷達上太乾淨的時候，它就在附近；撲空之後是破綻。
  - 冷凍光束會讓你變慢，被打中先拉開距離，不要往前衝。
- **WRECKER**：
  - 被魚叉鉤住立刻 QB 掙脫；搥胸之後是破綻。
  - 實彈有效、爆發沒用；雙拳搥地時跳起來。
- **SHRIKE**：
  - 俯衝前地上會有路線；打到失衡它會掉下來。
  - 爆發有效、能量沒用；翼下的導彈和腹下的炸彈艙可以拆。
- **VESPER**：
  - 先打掉腹下的發射器，浮空地雷才會停。
  - 抗實彈、弱能量；捕捉和俯衝斬落空都是破綻。
- **SCORIA**：
  - 它靠近會站起來；拍地時跳，熊抱撲空再打。
  - 熔岩塊落地會燒，榴彈砲看落點圈躲。
- **REGENT**：
  - 打到一半時可能會有別的東西衝進來。
  - REGENT 三種屬性都會用；磁軌砲的預警線一出現就橫移。
