# 敵方專用外觀（外觀和零件分開）

2026-11-24。使用者想要更多不同造型的機甲：現在的敵方機甲只是玩家零件（頭 5、核心 5、手臂 4、腳 6）的混搭，看起來都是那幾套的重新排列。定案先試「外觀和零件分開」：敵方機甲照舊用零件的數值與骨架，模型換成另一個外型。**第一支（WARDEN 警備機）放在模型庫的分類「暫時（敵方外型）」給使用者檢查，還沒有接到任何敵人。**

## 做法

- 組裝多一個欄位 `asm.look`＝外型的 id（`render/proc/index.js` 的 `LOOKS`）。
- `mech-model.js` 的 `mechPieces` 在每個區塊的資訊記 `look`＝`look/<外型>/<區塊>`（頭 `head`、核心 `core`、手臂 `r_upper`／`r_fore`／`r_hand`、腳 `pelvis`／`r_thigh`／`r_shin`／`r_foot`，左側 `l_…`）。區塊的槽位、骨架、部位判定、貼地都照舊是零件的；只有模型（`makeProcPiece0`）改用外型的清單，而且一律是程式模型（不問模型來源的 GLB）。
- 外型的腳只有二足的（基底零件的腳不是二足時，腳照零件的外觀）；背包與武器不換。
- 外型可以有自己的連接點（`joints`，glTF 座標，`LOOK_JOINTS`，`connOf` 先看它）：WARDEN 把脖子抬高。
- **清單是手寫的新設計，造型語言照現有的機甲**（2026-11-24 使用者定案，三次退回之後）：`render/proc/look_<外型>.js`。
  - 第一、二版：用放樣與方塊從零手刻，每塊只有一百多個三角形，精緻度和造型跟現有機甲差太多（「好醜」）。
  - 第三版：拿現有區塊拼裝、加掛，精緻度對了，但不是新設計（「你只是拼裝現有的模型」）。
  - 現在的做法：先近拍現有區塊研究它們的語言——**深色的塊狀骨架（關節、連桿）外面浮著一塊塊切角的多面裝甲，裝甲之間留縫、邊緣露出深色的襯底**——再用 `look_kit.js` 的 `chunk(色槽, 角點, 切角)`（一組角點的凸包，邊與角自動切過）一塊一塊寫：每個區塊先寫骨架（色槽 2）、再寫裝甲（色槽 0）、襯底與小零件（色槽 1）、標示（色槽 3）。角點用 `bx`（方塊）、`rX`／`rY`／`rZ`（某個位置上的矩形，接起來就是收窄或歪斜的塊）、`zz`／`xx`（前後或左右對稱的點）。
  - `pick`／`xf`／`recolor`（拿現有清單拼裝）還留在工具裡，`pieces` 也可以是函式 `pieces(PROC_PRIMS)`，但新外型不要用拼裝的。
- 右側的手臂與腳照寫的、左側是鏡像。色槽 0～3 跟著配色，4 起是外型自己的固定色（`cols`）。
- 縮放或另外設計比例會移動連接點的時候，在外型的 `joints` 補上新的位置。

## 參考與造型的原則

- 《機戰傭兵6》：各陣營連小兵的戰術都照陣營的性格設計，外觀也一眼分得出陣營。
- 《機動戰士鋼彈》：敵我用不同的形狀語言（一邊方正、一邊圓弧與單眼），遠遠看輪廓就知道是哪一邊。
- 所以敵方外型先定一個主題與輪廓，和玩家的機體（方正、細長、多面）拉開；**不照抄現成作品的機體**。第一版的鐘形腿＋圓肩＋橫向單眼太像既有動畫的量產機，改掉了。

## WARDEN 警備機

基底零件 h_std／c_std／a_std／l_bp 的骨架（脖子抬高），手掌沿用 GRANITE 的。輪廓：

- 頭：低矮寬扁，埋在領口裡；往前壓低的眉、眉底下一條橫的護目鏡、往前收的下顎、往後掠的頰翼、後方一支感測桅。
- 核心：往前突出的楔形胸（像推土機的鏟頭，上寬下窄）、兩側的進氣口、倒三角的上身、後高前低的護領。
- 上臂：山形的雙層大肩甲（上層內高外低、下層往外張的垂甲）。
- 前臂：往手腕變粗的護手、外側高過手肘的護刃。
- 襠部：前襠的楔形護甲、前腰往外下斜的護甲、腰帶上的掛箱。
- 腳：大腿正面與外側的掛甲、蓋過膝蓋的尖護膝、厚小腿與小腿肚的推進口、蹄形的寬腳掌與腳跟的穩定爪。

約 17,500 三角形（含武器；玩家初始機約 26,400）。和現有機甲比，面還是比較規則（大多是軸向的塊）、密度也低一些。

檢查：模型庫的分類「暫時（敵方外型）」或 `#temp/look_warden`，截圖 `node scripts/model-shots.js temp/look_warden`。

## 還沒做

- 接成敵人：敵人定義與生成紀錄要帶 `look`（多人的客機也要），部位判定的外框、槍口、受損的掉板要實際看過。
- 動作時的穿插（塔盾和肩上武器、裙甲和大腿）沒有檢查過。
- 外型只有程式模型，沒有 GLB 的版本。
