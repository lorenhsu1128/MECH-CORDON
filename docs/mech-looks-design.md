# 敵方專用外觀（外觀和零件分開）

2026-11-24。使用者想要更多不同造型的機甲：現在的敵方機甲只是玩家零件（頭 5、核心 5、手臂 4、腳 6）的混搭，看起來都是那幾套的重新排列。定案先試「外觀和零件分開」：敵方機甲照舊用零件的數值與骨架，模型換成另一個外型。**第一支（WARDEN 警備機）放在模型庫的暫時分類給使用者檢查，還沒有接到任何敵人。**

## 做法

- 組裝多一個欄位 `asm.look`＝外型的 id（`render/proc/index.js` 的 `LOOKS`）。
- `mech-model.js` 的 `mechPieces` 在每個區塊的資訊記 `look`＝`look/<外型>/<區塊>`（頭 `head`、核心 `core`、手臂 `r_upper`／`r_fore`／`r_hand`、腳 `pelvis`／`r_thigh`／`r_shin`／`r_foot`，左側 `l_…`）。區塊的槽位、骨架、部位判定、貼地都照舊是零件的；只有模型（`makeProcPiece0`）改用外型的清單，而且一律是程式模型（不問模型來源的 GLB）。
- 外型的腳只有二足的（基底零件的腳不是二足時，腳照零件的外觀）；背包與武器不換。
- 外型可以有自己的連接點（`joints`，glTF 座標，`LOOK_JOINTS`，`connOf` 先看它）：WARDEN 把脖子抬高。
- 清單是手寫的（`render/proc/look_<外型>.js`），造型工具在 `render/proc/look_kit.js`（放樣 `loft`／`stackX`／`stackY`／`stackZ`、八角截面 `oct`、圓柱 `cyl`、斜板 `plate`、旋轉位移 `tf`、左右各一份 `both`）；右側的手臂與腳照寫的、左側是鏡像。色槽 0～3 跟著配色，4 起是外型自己的固定色（`cols`）。

## 參考與造型的原則

- 《機戰傭兵6》：各陣營連小兵的戰術都照陣營的性格設計，外觀也一眼分得出陣營。
- 《機動戰士鋼彈》：敵我用不同的形狀語言（一邊方正、一邊圓弧與單眼），遠遠看輪廓就知道是哪一邊。
- 所以敵方外型先定一個主題與輪廓，和玩家的機體（方正、細長、多面）拉開；**不照抄現成作品的機體**。第一版的鐘形腿＋圓肩＋橫向單眼太像既有動畫的量產機，改掉了。

## WARDEN 警備機

主題＝封鎖線的鎮暴警備，像路障一樣的平板：低矮的頭盔縮在高領裡、三道直立的格柵鏡；桶形的胸＋船首形的胸甲；掛在肩外側的塔盾（斜的警戒條紋）；外側有高護板的前臂；前後的短裙甲與腰側的裝備箱；直筒的小腿＋蓋過膝蓋的大護脛；寬腳掌。基底零件 h_std／c_std／a_std／l_bp，手掌沿用 GRANITE 的。約 14,600 三角形（含武器；玩家初始機約 26,400）。

檢查：模型庫 `#temp/look_warden`，截圖 `node scripts/model-shots.js temp/look_warden`。

## 還沒做

- 接成敵人：敵人定義與生成紀錄要帶 `look`（多人的客機也要），部位判定的外框、槍口、受損的掉板要實際看過。
- 動作時的穿插（塔盾和肩上武器、裙甲和大腿）沒有檢查過。
- 外型只有程式模型，沒有 GLB 的版本。
