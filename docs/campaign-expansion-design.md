# 主線擴充：新玩法、章節、僚機與宿敵、掉落與調校

2026-11-08 起草、定案。使用者通過第 1 周目後的回饋：主線太短、玩法太單一，後面幾關無聊。
從同類遊戲的特色提案中選定：**A1～A6（新任務玩法）、B3（傳說模組）、B4（敵人詞綴）、C1（新章節）、C2（委託板）、D1（僚機）、D2（宿敵）、E1（掉落）、E2（調校）**。

定案見第 8 節。

---

## 0. 問題與方向

- 第 1 周目約 17 個出擊、每個 4～5 段，全程約 70～80 段。每一段都是「進 230 m 的場地 → 打幾波 → 清除 → 走出口」，區段類型（破壞、防衛、護送、情報…）只換目標，核心流程一樣。
- 戰術模組多半是數值加成，選了之後打法不會變。
- 方向：先做**節奏不同的新區段類型**（A），把它們混進既有出擊與新章節；再做讓打法改變的成長（B3、E），最後補內容量（C）與角色（D）。

## 1. 共用的基礎：區段類型的處理表

現在區段類型的分支散在很多地方：`campaign.js` 的 `ADVANCE`、`campSegWorld`、`campTypeOk`、`campEnterSeg`、`campSpawnType`、`campBlockClear`、`campTick`、`campGoal`，以及 `goals.js` 的 `goalSpec`、`campaign-mp.js` 的 `campView`、`crowd-themes.js` 的 `CROWD_SEG`、`hub.js` 的簡報情報、`story-comms.js` 的 `segStart`。新增 6 種類型前先整理成一張表：

```js
// game/seg-types.js（mixin 不能 export，所以表放 data/seg-rules.js，處理函式掛在 Game 上）
SEG_TYPES.stealth = {
  name: '潛入',
  goal: '不被發現，取得情報',
  world: { zone: 'long', big: true }, // campSegWorld 的覆寫
  ok: (w) => true, // campTypeOk
  outposts: false,
  devices: true,
  crowd: 'sparse',
  mp: true, // 多人可用；false 時在多人改抽 pool 裡的其他類型
};
// Game 端：segSpawn_<type>()、segTick_<type>(dt)、segBlock_<type>()、segGoal_<type>()、segView_<type>()
```

- 舊類型照舊走原本的 if/else，新類型一律走處理表（之後再慢慢搬舊的）。
- 區段的執行狀態照舊放 `c.ss`；需要轉給客機的放進 `campView`。
- 每種新類型都要有：開場通訊（`story-comms.js` 的 `segStart`）、過關條件卡片（`goalSpec`）、簡報情報、出口預告的文字與圖示、冒煙測試。

## 2. A：新任務玩法（新的區段類型）

### A1 大型兵器 `colossus`

參考 AC6 的冰蟲、AC for Answer 的 Arms Fort、ZOE2 的艦隊戰。

- **流程**：
  1. **追擊與拆解**：巨大兵器沿路線緩慢移動，身上有砲台、引擎（腳）、雷達、裝甲板等部位，各自可以鎖定與破壞。
  2. **停機**：引擎全部打壞就倒下或停住，變成靜止的地形。
  3. **攻入核心**：上方或側面打開艙口，露出核心。在時限內打壞核心（核心會放大招，打斷用 Boss 改版的 I 規則）。
- **為什麼要分「移動時」與「停機後」**：移動中的平台要做會動的碰撞（機體站在上面跟著走），成本高而且多人很難同步。所以移動時只能從外面打，停機後才把它的甲板登記成 `addDeck`／障礙物，玩家可以站上去。
- **三種**（各章輪流用）：
  - 陸上步行要塞：四或六隻腳，打斷腳才停機。
  - 陸上戰艦：履帶加多座主砲，沿公路前進，到終點就失敗（兼有 A3 追擊）。
  - 空中巨艦：和 A5 空戰段落合併。打掉引擎後迫降，地面段落再攻核心。
- **沿用**：Boss 改版的部位 `bpart`（`opts.off`、`hpAbs`、`tierPartLost`）、空中要塞、武裝列車的路線、部位的血量與同步、`addDeck`。
- **新內容**：3 個巨大程式模型（`render/colossus-models.js`，精細度照 `docs/model-detail.md`）、部位的掛點、停機的倒下演出、核心艙口。
- **效能**：模型很大，要跑 `perf-campaign.js` 量卡頓，倒下時的碎片沿用破壞改版的分格。

### A2 潛入 `stealth`

參考 AC6 的潛入任務、MGS 系列。

- **目標**：在不觸發警報的情況下抵達資料終端，或暗殺指定目標，或取回物資。
- **警報**：任何敵人進入交戰（`senseEngage`）時，`ss.alarm` 開始：
  - 全場敵人交戰，增援從邊緣湧入（沿用 waves）。
  - 情報類：資料開始被刪除，倒數 60 秒內要下載完，否則只拿到一半的報酬（不判失敗）。
  - 暗殺類：目標開始撤離（變成 A3 追擊）。
- **玩家的工具**：
  - 背刺：從背後（±60°）對待機或起疑中的敵人近戰，一擊擊破、不發出聲音。
  - 移動的聲音：QB、開火、跳躍會發出聲音（現有的 `aiNoise`），走路很小聲。
  - 視線：名牌上的察覺量表（現有 `drawAwareMark`）一律顯示；監視器與探照燈的錐形範圍畫在地上。
- **新的地圖裝置**：監視攝影機（固定轉動、看到就直接警報，可以打壞，但打壞時有聲音）、探照燈塔（沿用 hazards2 的 `spot` 區域）、雷射柵欄（沿用保全雷射網 `laserpost`）。
- **評價**：沒有觸發警報時報酬加成；HUD 顯示「未被發現」。
- **多人**：可以。任何一個人被發現就全體警報。

### A3 追擊 `chase`

參考 Titanfall 2 的列車關、Ace Combat 的追擊任務。

- 狹長作戰區域（`zone: 'long'`），目標車隊、列車或運輸機沿著公路／鐵路往終點逃，**到終點就失敗**。
- 作戰區域跟著目標往前擴張，後面收起（沿用 `staged` 的 `expandZone`）。
- 沿途有攔截的敵人與路障（沿用破壞改版的臨時障礙物）。目標本身會反擊，並且可以打斷它的引擎讓它減速。
- **沿用**：護送車隊 `campConvoy` 的路線（改成敵方）、武裝列車的鐵路、`corridorPoint`。

### A4 撤離 `extract`

參考 Helldivers 2、Mecha BREAK 的 Mashmak。

- **流程**：
  1. 完成主要目標（打壞設施或拿到物資）。
  2. 呼叫回收。接應點在地圖另一側，回收機 90 秒後抵達。
  3. 等待期間增援一波比一波兇，最後一波有敵對 AC。
  4. 回收機到了之後，站進接應圈 5 秒就撤離成功。
- **戰利品**：地圖上散落的物資箱（E1 的素材）要**撤離成功才帶得走**。半路陣亡從紀錄點重來時，這一段撿到的全部不算。
- 可以提早撤離：帶走的少，但安全。
- **多人**：可以。全員進圈或倒下的人以外全員進圈就撤離。

### A5 空戰段落 `air`

參考 Ace Combat。

- 讓主線的某些區段使用空域地圖（`airspace`）：攔截轟炸機群、護送運輸機、和 A1 的空中巨艦交戰。
- 要做的事：
  - `campEnterSeg` 在玩家建好之後呼叫 `airBegin`／`airSpawn`，略過據點、地圖裝置、小人。
  - `airPlayerTick` 的雷達站被毀目前是直接 `endMission(false)`，主線時要改成 `campDead`。
  - 擊破時的 `airKilled` 也要給主線的報酬。
  - 轉場（`THEME_MODE`／`TRANSITIONS`）要加空域：從運輸機彈射。
- **多人**：空域目前只有單人。多人時這種區段改抽 pool 裡的其他類型（`mp: false`）。空戰支援多人（空戰導彈、被咬尾等都要同步）工程量很大，先不做。

### A6 大規模戰場 `front`

參考 EDF、ZOE2。

- 友軍部隊（MT、載具、1～2 台友軍 AC）和大批敵人對推戰線。地圖上有 3 個據點，依序佔領（站在圈裡、敵人比我方少時進度上升）。
- 敵人數量是平常的 2～3 倍，但大部分是弱的雜兵（AP 低、一兩發擊破）。爽快感來自一次打倒很多台。
- 戰線狀態顯示在 HUD 上方（三個據點的歸屬）；友軍據點被搶回時通訊求援，引導玩家去最吃緊的方向。
- **效能**：同時在場的機體有上限（例如敵我合計 40 台）。超過時新的增援在畫面外排隊。弱雜兵用簡化的 AI（不走攻擊權杖，只朝最近的據點推進）。一定要跑 `perf-campaign.js`。
- **沿用**：友軍（`team: 'ally'`、`allyDur: 1e9`）、增援波次、地圖上的小人當步兵。

### 新類型放進既有出擊

- 第 1～6 章的出擊各挑 1～2 段，把 pool 換成新類型，所以第 1 周目重玩也會遇到。
- 第 2、3 周目的委託優先放新類型。
- C2 委託板與第 7、8 章大量使用新類型。

## 3. B：改變打法的模組與敵人

### B3 傳說模組

參考 Hades 的祝福。

- 新增一級「傳說」（金框），效果是**改變武器或機動的行為**，不是數值加成。一次出擊最多持有 2 個。
- **取得**：精英區段、Boss、A1 大型兵器擊破後的三選一，固定有一個是傳說模組；出口獎勵有少量 `mod_legend`。
- **每家委託方 4 個**，照原本的風格（卡斯特隆＝實彈、艾瑟立克＝能量、維爾威＝機動、聖域＝防禦）。初版提案：

| 委託方   | 名稱       | 效果                                              |
| -------- | ---------- | ------------------------------------------------- |
| 卡斯特隆 | 分裂彈頭   | 導彈命中時分裂成 3 枚小導彈追蹤附近的敵人         |
| 卡斯特隆 | 貫穿彈     | 實彈貫穿第一個目標，打中後面的目標                |
| 卡斯特隆 | 連鎖殉爆＋ | 擊破的敵人爆炸，爆炸再引爆附近 AP 低於 20% 的敵人 |
| 卡斯特隆 | 彈幕傾瀉   | 換彈時把彈匣剩下的子彈一次散射出去                |
| 艾瑟立克 | 折射雷射   | 雷射命中後折射到最近的另一個敵人（傷害 60%）      |
| 艾瑟立克 | 過載核心   | EN 用完時放出電磁脈衝，附近敵人失衡量 +50%        |
| 艾瑟立克 | 電弧刃     | 近戰命中時電弧跳到 2 個附近的敵人                 |
| 艾瑟立克 | 蓄力共鳴   | 蓄力射擊命中後 3 秒內，所有能量武器免 EN          |
| 維爾威   | 殘影       | QB 時留下誘餌殘影，吸引敵人開火 2 秒              |
| 維爾威   | 電弧推進   | QB 的路徑留下電弧，碰到的敵人受傷                 |
| 維爾威   | 落雷踐踏   | 從高處落地時產生地面衝擊波                        |
| 維爾威   | 追擊推進   | 擊破敵人後 2 秒內 QB 不耗 EN                      |
| 聖域     | 反應裝甲   | 受到近戰攻擊時自動反擊爆炸                        |
| 聖域     | 護盾轉化   | 護盾（脈衝盾）吸收的傷害累積成下一發的額外傷害    |
| 聖域     | 不死鳥     | 每段一次，AP 歸零時以 30% 復活並放出衝擊波        |
| 聖域     | 堡壘       | 站著不動 1 秒後減傷 40%，並且 ACS 不累積          |

- **組合技**：同時持有兩家的傳說模組時出現「共鳴」（例如殘影＋分裂彈頭＝殘影也會發射導彈）。初版 4 個，之後再加。
- **實作**：模組的 `fx` 加旗標，行為寫在對應的地方（`fire`、`takeDamage`、`move` 的 QB），只在房主／單機判定；外觀用會轉送的 fx。
- 白話說明、適用性（`MOD_TIPS`、`modFit`）一併補上。

### B4 敵人詞綴

參考《暗黑破壞神》的精英怪、Returnal。

- 一般敵人（不含 Boss、部位、目標物）有機率帶 1～2 個詞綴。機率依章節與等級上升：第 1 章約 5%，第 6 章約 15%，第 2、3 周目再加。
- 名牌換成金色、標詞綴圖示，鎖定提示寫出效果。帶詞綴的敵人 AP ×1.5，報酬 ×2，一定掉落（E1 的素材，有機率掉零件）。
- **詞綴（初版 10 種）**：

| 詞綴 | 效果                         | 對策                 |
| ---- | ---------------------------- | -------------------- |
| 護盾 | 前方有能量護盾               | 繞背、近戰           |
| 分裂 | 擊破時分成 2 台小型          | 範圍攻擊             |
| 隱形 | 沒開火時半透明、不能鎖定     | 看到開火立刻反擊     |
| 狂暴 | AP 低於一半時速度與火力 +40% | 一口氣打完           |
| 反射 | 每隔幾秒反射實彈             | 看準時機、用能量武器 |
| 再生 | 3 秒沒被打就回復 AP          | 持續施壓             |
| 殉爆 | 擊破時大爆炸                 | 保持距離             |
| 疾風 | 移動與 QB 很快               | 霰彈、預判           |
| 磁力 | 把附近的導彈吸過去           | 不用導彈             |
| 指揮 | 附近的敵人也帶它的另一個詞綴 | 先打它               |

- **同步**：生成紀錄帶 `af`（詞綴位元）；外觀（金色名牌、護盾、半透明）各端依 `af` 自己做。
- 自由出擊也有（低機率）。

## 4. C：內容量

### C1 新章節：第 7、8 章

- **位置（定案：結局前）**。目前第 6 章 c6s3 是 `final`（結局、下一周目）。兩個做法：
  - **(建議) 插在結局前**：第 6 章結尾改成轉折（軌道站揭露真正的敵人），第 7、8 章是新的最終篇，最後的抉擇 `c6` 移到第 8 章的最後一個出擊。要改劇本（`docs/story-script.md`）、第 6 章的章末過場、結局的條件。
  - **放在結局後**：第 7、8 章是「後日談」，第 1 周目結局後才開放。不用改原本的劇情，但第 1 周目的長度不會增加。
- **兩個新主題（定案）**：
  - 第 7 章「火山熔爐帶」`volcano`：熔岩河（掉進去持續受傷，類似虛空的拉回）、噴發的地形事件、熔爐工廠、黑煙天候。
  - 第 8 章「移動要塞『方舟』」`ark`：在巨大要塞的甲板與外殼上作戰（多層，沿用 Grid 086 的平台），最後一個出擊攻進要塞內部。A1 大型兵器的集大成。
- **每章的內容（照前 6 章的規格）**：
  - 主題本體、6 種變體、6 個地標、邊界景觀、天候、環境音與殘響、水面／熔岩的外觀。
  - 4 種專屬敵人（含模型、受損、動作）、1 台專屬 AC、2 隻新 Boss（含 `BOSS_KIT`、刁鑽度、場地效果）。
  - 3～4 個出擊，含一次陣營抉擇；第 2、3 周目各 1 個委託；記憶片段 2 片（第 3 周目）。
  - 劇本、簡報、通訊、章節開場／章末過場動畫、ECHO 與其他角色的語音（VoxCPM2 產生，要在有 CUDA 的電腦上跑）、日文台詞。
  - 戰區總覽圖的新區域（`REGIONS`）、作戰室的全像地形。
  - 卡頓檢查 `perf-campaign.js --ch=7`／`--ch=8`。
- `NET_VERSION` 要提高（新主題）。

### C2 委託板（支線）

參考 AC6 的委託、Titanic Scion 的自由戰鬥。

- 作戰室多一個設施「委託板」。每章開放 3～5 個短委託，每個 1～2 段，不算進整章完成，可以重複接。
- 每個委託帶一條**特殊規則**（`rules`），初版 12 種：
  - 限時 5 分鐘。
  - 禁用導彈／禁用近戰。
  - 只能用近戰。
  - 指定組裝（借用的機體）。
  - AP 30% 開始、沒有修復套件。
  - 敵人全部帶詞綴。
  - 濃霧，雷達失效。
  - 一擊必殺（雙方的傷害 ×5）。
  - 不准 QB。
  - 潛入，被發現就失敗。
  - 撤離，物資加倍。
  - 只有空中跳（不能落地超過 3 秒）。
- **報酬**：COAM、素材、傳說模組的「預約」（下一次出擊的第一個三選一必定出現某一個），以及委託限定的零件與配色。
- 委託每完成一次就換新的（從該章的委託池抽），作戰室的委託板顯示剩餘的。
- 多人也能接（房主的委託板）。

## 5. D：角色

### D1 僚機

參考 AC6 的 Rusty、Titanfall 2 的 BT。

- **僚機（定案：新角色兩位）**，各自跟一條陣營路線：
  - 卡斯特隆／維爾威路線：一位老練的傭兵。
  - 艾瑟立克／聖域路線：一位新人。
  - 也可以用既有的角色（例如霍斯特旗下的駕駛員、劇本裡的宿敵改成共同作戰）。
- **出場**：部分出擊整次同行（簡報寫「僚機同行」），之後的委託板也可以花 COAM 雇用。
- **行為**：友軍 AC（`team: 'ally'`、`allyDur: 1e9`），AI 跟著玩家、優先打玩家鎖定的目標。AP 歸零時「失去戰鬥能力」而不是擊破：站在旁邊 3 秒就能救起來。整段沒救就在下一段之前回來，但好感度下降。
- **簡單指令**（十字鍵／鍵盤）：集中攻擊我的目標、自由攻擊、跟著我、守在這裡。
- **對話**：開場、擊破精英、被救起、救了玩家、完成時的台詞（`story-comms.js` 新事件 `wing*`）。
- **好感度** `save.story.bond[僚機]`：依救援、共同擊破、任務完成累積，影響結局的台詞，以及第 3 周目的一個專屬委託。
- **多人**：多人不帶僚機（人已經夠多）。

### D2 宿敵

參考《中土世界：魔多之影》的宿敵系統。

- **誕生**：玩家被敵對 AC、帶詞綴的敵人或精英擊倒時（`lastHitBy`），它晉升成宿敵，記進 `save.story.nemesis`，最多同時 3 個：
  - 名字：具名 AC 沿用原名，雜兵產生稱號（例如「斷刃的 MT-7」）。
  - 組裝、等級、勝場、傷疤（被玩家打壞過的部位）、擅長的打法。
- **成長**：每擊倒玩家一次就升級，換更好的零件，並針對玩家最常用的武器類型加抗性（沿用複製 AC 的適應裝甲）。
- **再登場**：之後的出擊有機率在某一段「插隊」登場（開場的通訊：「又見面了」），也可能在其他敵人交戰時闖進來。
- **擊破**：擊破宿敵給大量 COAM、它的零件（E1），以及一句結算台詞。被擊破兩次的宿敵退場；也有一定機率「還沒死」，改名再回來。
- **台詞**：用模板（稱號、上次在哪裡、上次怎麼贏的），所以不用每個宿敵都錄語音；語音只錄通用的幾句（系統的無線電腔調）。
- **多人**：宿敵記在被擊倒的那位玩家的存檔裡。多人時由房主的宿敵登場（以後再擴充）。

## 6. E：成長

### E1 掉落

參考鋼彈創壞者 4。

- **素材**（新的貨幣，存檔 `save.mats`）：合金、電子零件、能量核心、稀有的「傳說殘片」。
  - 掉落：擊破敵人（帶詞綴、精英、Boss 較多）、撤離的物資箱、委託報酬、可破壞的地圖物件裡的物資。
- **零件**：擊破具名 AC、宿敵、Boss 時有機率掉一個它裝備的零件（還沒擁有的優先）。撿到就直接加進 `save.owned`，結果畫面列出「新零件」。
- 掉落物是 `PICKUP_DEFS` 的新種類（`mat`、`part`），撿取沿用 `collectPickup`。多人時各自撿、各自入帳（房主送事件）。

### E2 調校

參考 AC 系列的調校。

- **調校的方式（定案：依零件種類）**。考慮過的兩種做法：
  - **(建議) 依零件種類調校**：`save.tune[零件 id] = { 項目: 級數 }`，同一種零件全部一樣。存檔與多人的轉送都簡單（駕駛員加成的 payload 多一份，房主校正）。
  - 每個零件是獨立物品、帶隨機詞條：收集性強，但存檔、機甲庫、多人都要大改（組裝要從零件 id 改成物品編號）。不建議。
- **調校項目**（每個零件 3 個欄位，每格 3 級，有取捨）：
  - 武器：傷害↔射速、彈匣↔裝填、射程↔擴散、衝擊↔重量。
  - 機體：AP↔重量、防禦↔EN 負載、速度↔穩定。
  - 推進器：QB 推力↔耗能。
- **費用**：素材＋COAM。級數越高，素材要越稀有。可以重置（退還一半）。
- **藍圖**：宿敵、委託報酬給的「藍圖」解鎖特殊調校，例如霰彈槍的獨頭彈（擴散極小、射程長）、導彈的高機動彈頭。
- 機甲庫的零件小卡片與規格頁顯示調校後的數值。理論火力與靶場也要算進去。
- PvP 不套用調校（公平），自由出擊照樣套用。
