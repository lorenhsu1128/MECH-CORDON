# 進出各功能的路徑（返回路徑）

2026-11-13 使用者回報「進入機甲庫的按鈕有些地方會亂跳」。全部的畫面與按鈕整理過一遍（流程測試把每條路線實際按過）之後，使用者定案 A～H 全做。

## 問題（調查結果）

1. **回不到剛才的地方**：自由出擊的機甲庫有「前往作戰室」，作戰室卻只能「回標題」；從簡報按「先去機甲庫整備」，返回時跳回作戰室的總覽；模擬戰打完回作戰室（同一個模擬器裡的訓練課程卻回模擬器）；作戰紀錄的重打完回作戰室；轉場畫面按了「進機甲庫整備」就退不回去。
2. **設定只有標題與任務中的暫停選單**才開得到；機甲庫的「設定」分頁其實是機體的設定（配色、地圖…），和遊戲設定撞名。
3. **同一個東西不同名字**：「返回標題」／「回標題」；作戰室的設施標籤和下方圖示列（通訊台／通訊紀錄、模擬艙／模擬器、存檔終端／存檔）。
4. **標題太擠**：17 個按鈕裡 9 個是工具。
5. **存檔兩套介面**：標題的「選擇存檔」和作戰室的「存檔終端」內容不同，抉擇前備份只有存檔終端看得到。
6. 程式面：「從哪裡來」靠各自的旗標（`fromHub`、`fromLevels`、`garageBrief`、`pilotFromHub`），每加一個入口都容易漏。

## 定案與做法

### A 返回路徑（`game/nav.js`）

- 每個可以從好幾個地方進來的畫面記下返回要回哪裡：`navSet(畫面, 目的地, 參數)`，返回鍵一律 `navGo(畫面)`，文字 `navLabel(畫面)`＝「返回＋目的地」。取代上面那些旗標。
- 畫面：`garage` 機甲庫、`hub` 作戰室、`pilot` 駕駛員（設定照舊用 `settingsFrom`：title／pause／hub／garage）。
- 目的地與文字：

| 目的地 | 文字 | 去哪裡 |
|---|---|---|
| title | 返回標題 | 標題 |
| hub | 返回作戰室 | `openHub`（作戰室自己的返回路徑照舊） |
| brief | 返回簡報 | `openHub` 再 `openBrief(出擊 id)` |
| freeGarage | 返回機甲庫 | 自由出擊的機甲庫（`openFreeGarage`：機甲庫的返回重設成標題） |
| garage | 返回機甲庫 | `openGarage`（機甲庫自己的返回路徑照舊） |
| levels | 返回關卡選單 | 自訂關卡選單 |
| camptrans | 返回轉場畫面 | 轉場畫面（不出擊，按鈕直接顯示） |
| campfail | 返回 | 失敗／撤退畫面 |

- **機甲庫的場合**（`garageMode`）：多人 mp → 轉場整備 trans（`camp.inGarage`）→ 返回目的地是 hub／brief＝主線整備 hub → levels＝自訂關卡整備 lv → 其他＝自由出擊 free。按鈕的顯示（`campaign.js` 的 `campGarageUi`）、作戰卡（`free-ops.js` 的 `garageOpsUi`）、格納庫的場景（`hangar.js` 的 `hangarKind`）都照它。
- **誰設定**：標題的「自由出擊」、存檔畫面的「自由出擊／新的傭兵生涯」、自由出擊的結果＝`openFreeGarage`（返回標題）；作戰室的「機甲庫」＝hub；簡報的「先去機甲庫整備」＝brief；自訂關卡的「機甲庫（整備）」＝levels；轉場畫面與失敗畫面的「進機甲庫整備」＝camptrans／campfail；作戰室：標題的「主線」與存檔畫面的「主線」＝title，自由出擊機甲庫的「前往作戰室」＝freeGarage；駕駛員：作戰室＝hub、機甲庫＝garage。靶場、作戰設定、駕駛員、設定回到機甲庫時不改它的返回路徑。
- 新增會進機甲庫或作戰室的入口時：進去之前 `navSet`，不要再加旗標；新的目的地加在 `nav.js` 的 `LABEL` 與 `navGo`。

### B 設施結束回到設施

- 模擬戰的結果「返回模擬器」（`sim.js` 的 `simEnd`：`resultNav = 'sim'`）、作戰紀錄的重打「返回作戰紀錄」（`campEnd`：`camp.replay` 而且不是自由出擊）。結果畫面的確定（`input.js` 的 `btnResultOk`）先 `openHub` 再開那個設施的清單。

### C 設定的入口

- 作戰室下方圖示列與機甲庫底部加「設定」（`openSettings('hub'|'garage')`，`closeSettings` 回原本的畫面；機甲庫的場合與返回路徑照舊）。
- 機甲庫的「設定」分頁改名「機體設定」。

### D 用語

- 返回鍵一律「返回＋目的地」（「回標題」全部改成「返回標題」，失敗畫面「返回作戰室（保留紀錄點）」）。手把的 B 鍵靠文字找返回鍵（`pad-ui.js` 的 `BACK_RE`），新增返回鍵照這個寫法。
- 作戰室的設施標籤和下方圖示列同一個名字（`hub-holo.js` 的 `HUB_SPOTS`）：機甲庫、駕駛員、委託方、通訊紀錄、ECHO 的紀錄、章節回顧、模擬器、作戰紀錄、存檔。

### E 標題

- 主選單只留遊戲的入口：主線、自由出擊、選擇存檔、多人、自訂關卡、設定、操作說明、「工具與其他…」、全螢幕（平板靠它離開全螢幕，留在外面）。
- 其他（轉換舊存檔、模型庫、文字動畫、貼圖繪製、角色產生器、渲染風格、地圖預覽、過場動畫、ECHO 語音試聽、配樂試聽、重新載入本地模型）收進 `#titleTools` 面板（同操作說明的置中面板）；離開標題時面板收起（`showScreen`）。冒煙測試點這些按鈕用 `titleTool(page, 選擇器)`（先打開面板）。

### F 轉場整備可以返回

- 單人的轉場整備多一個返回鍵（從轉場畫面來＝「返回轉場畫面」、從失敗／撤退畫面來＝「返回」），回去不出擊；多人照舊只有「繼續作戰」。

### G 冒煙測試

- `testNavFlow`：上面每一條路線的場合、返回鍵文字與返回之後的畫面。

### H 存檔畫面

- 標題的存檔畫面和存檔終端用同一份摘要（`save.js` 的 `slotSummary`：主線的周目與章節、進行中的出擊、自由出擊的任務與擊破、SP、駕駛員、最後遊玩），每張卡片有「主線」「自由出擊」兩個入口；抉擇前備份也顯示（每個存檔最近一份，「讀回」確認後取代那個存檔並改用它）。
