# 載入提示（2026-11-16）

全畫面的載入畫面（`#loadCover`）與主線的轉場畫面（`#campTrans`）下方的提示卡：ECHO 的口吻與小頭像，隨機抽一則遊戲提示，停留超過 6 秒換下一則。

## 定案（使用者，2026-11-16）

| 項目       | 決定                                                                                                        |
| ---------- | ----------------------------------------------------------------------------------------------------------- |
| 語氣       | ECHO 的口吻（冷靜、短句、乾冷的幽默、叫玩家「傭兵」，`docs/story-script.md` 的 ECHO），卡片放 ECHO 的小頭像 |
| 位置       | 載入畫面與轉場畫面都放                                                                                      |
| 數量       | 100 則以上（手寫約 150 則＋遊戲資料產生的情報）                                                             |
| 爆雷       | 沒遇過、沒解鎖的內容隱藏                                                                                    |
| 世界觀短句 | 要（依主線的進度，不爆雷）                                                                                  |
| 設定       | 「介面與演出」的「載入提示」`ctrl.tips`（顯示／不顯示）                                                     |
| 按鈕       | 寫功能名稱（「跳躍」鈕），不寫鍵盤的鍵；後面附依裝置自動產生的鍵帽（玩家改過的按鍵也對）                    |
| 近戰派生   | 只寫通用的說法（前派生、上挑、側派生），不分武器                                                            |
| 依裝備加權 | 要：兩手不同屬性的抽「輪流打觸發反應」，同一種屬性的抽「換一把別的屬性」                                    |

## 資料（`src/data/tips.js`）

- `TIPS`：`{ id, c 分類, t 文字, only, boost, ch, cyc, seenBoss, w }`。
  - `t` 是字串，或依裝置的 `{ kb, pad, touch }`（手把沒寫時用鍵盤的；少了的裝置不抽）。方向派生這種三種裝置操作不同的，寫三個版本（鍵盤「按著向前」、手把「左搖桿推著往前」、觸控「在射擊鈕上往上滑」）。
  - 文字裡的 `{jump}`、`{qb}`、`{ab}`、`{fire}`、`{melee}`、`{back}`、`{kit}`、`{use}`、`{lock}`、`{assist}`、`{wing}`、`{cs}`、`{aam}`、`{view}`、`{pause}` 換成「名稱」鈕＋鍵帽（`BTN`：名稱、按鍵設定的動作、觸控按鈕的字；`touch: null`／`pad: null`＝那個裝置沒有這顆，用到它的提示在那個裝置不抽）。`{melee}`＝拿近戰武器那隻手的武器鍵（觸控的版本改寫 `{fire}`，觸控的射擊鈕靠近敵人時自動變近戰）。
  - `only`：都要符合才抽（`theme`、`seg`、`dev`、`camp`、`air`、`boss`、`equip`）；`boost`：符合時加權（區段類型、主題、Boss ×4，裝備 ×2）；`ch`／`cyc`：至少第幾章、第幾周目；`seenBoss`：遇過 Boss 或下一段就是 Boss。
- 分類 `TIP_CATS`：操作、射擊、屬性、近戰、防禦、敵人、Boss、區段、地圖、裝置、整備、主線、空戰、情報、檔案。
- `tipWeight`／`tipPick`：純函式；最近看過的 24 則（localStorage `mech_cordon_tips_recent`）權重 ×0.02。空域只抽空戰、情報與檔案（其他 ×0.2）。

## 情報（`src/game/tips.js` 產生）

不手寫，從遊戲資料的 `intro` 與弱點（`weakText`）產生，數字永遠和遊戲一致：

- 一般的特殊敵人（`ENEMY_TYPES`）：不鎖。
- 主題專屬敵人（`FOES`）、宿敵（`ACES`）、Boss（`BOSS_DEFS` 有 `kind` 的）：存檔的 `story.seen2` 有記錄才出現（模擬器的紀錄，`simMark`）。下一段的主題的敵人 ×6；下一段要打的 Boss（遇過才有）×20。

## 顯示

- 情境 `tipCtx`：裝置（觸控＝虛擬按鈕、手把、鍵盤）、主線時下一段（轉場）或這一段（載入）的主題與區段類型與 Boss、主線的進度（完成過的出擊的最大章）、周目、遇過的紀錄、裝備的特徵（近戰、導彈、脈衝盾、屬性、混合／單一屬性）。
- `tipStart(id, force)`：`#lcTip`（`render-setup.js` 的 `loadCover`）、`#ctTip`（`campShowTrans`、多人客機的 `ctrans`、從機甲庫返回轉場）；元素看不到時停下。`force` 指定一則（截圖 `ui-shots.js load-tip`、冒煙測試 `testTips`）。
- ECHO 的頭像：`portrait-ui.js` 的 `ptFaceUrl('echo')`，第一次要等立繪載入，晚一點補上。
- 樣式：`styles.css` 的 `.tipCard`（黑底圓角卡、斜切的 TIPS 標籤、分類、ECHO、按鈕＝白字「名稱」鈕＋黑膠囊的黃字鍵帽），矮螢幕縮小。

## 新增提示

- 加在 `TIPS`：數字與機制先對過程式（`data/` 的常數、設計文件）；用到按鈕一律寫 `{按鈕}`；三種裝置操作不同時寫 `{ kb, pad, touch }`；新系統要不要等解鎖（`ch`／`cyc`／`only.camp`）。
- 新的敵人、Boss、宿敵只要有 `intro` 就會自動出現在情報裡。
- 冒煙測試 `testTips`；截圖 `node scripts/ui-shots.js load-tip,trans-real --size=all`。
