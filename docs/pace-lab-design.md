# 遊戲節奏調整室

2026-11-18 使用者要求：「一直在清怪、一直在射擊，也沒有感覺使用不同武器的不同之處，很難享受機甲閃躲或是連招」。
先不直接改遊戲的數值，做一個可以邊玩邊調的調整室，找到手感之後再決定要不要把數值寫回遊戲。

## 定案

- 入口：標題「工具與其他」的「節奏調整室」（`game/pace-lab.js` 的 `openPace`）。
- 參數只在調整室裡生效（`data/pace.js` 的 `PACE.on`），不影響正常的遊戲；不寫存檔、不給獎勵與經驗，被擊破就重新出場。
- 調整的是遊戲的基本設定，所以沒有任何加成（使用者定案）：機甲一律是預設機甲的組合（`START_ASM`，武器換成面板選的，見下一項），不帶駕駛員技能、零件品級與調校、戰術模組；敵人沒有詞綴、身上的零件沒有品級；射擊沒有邊閃邊打、蓄力的強力彈、主動裝填的加成；沒有風格評價、失衡連攜（`noBonus`、`syOn`、`afApply`、`gearEnemy` 看 `paceLab`）。直擊補正、弱點、屬性反應這類基本規則照舊。
- 設定組可以存好幾組（localStorage `mech_cordon_pace`），可以匯出、匯入 JSON；改了馬上生效。
- 每一把武器各自一組倍率（子彈速度、射速、傷害、衝擊）。面板的武器區是兩個選單（2026-11-18 使用者要求）：「手部武器」選了就雙手都換成那一把、「肩部武器」選了就雙肩都換成那一組（`paceAsm`，記在設定的 `cfg.hand`／`cfg.back`；任務中換選項時 `paceRespawn(true)` 在原地換上新機體），選單下面直接是這把武器的 4 項倍率。

## 參數（倍率，1＝現在的遊戲；遊戲速度是絕對值，預設 0.75）

| 分組             | 參數                                                                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 整體             | 遊戲速度                                                                                                                                      |
| 我方機動         | 移動速度、QB 速度、QB 耗能、突擊推進速度、EN 回復、跳躍力、QB 無敵時間、QB 冷卻（秒）、完美 QB 判定時間                                       |
| 我方射擊         | 子彈速度、射速、傷害、衝擊、裝填時間、擴散、彈道修正、導彈追蹤力                                                                              |
| 近戰             | 近戰傷害、突進距離、頓格、連段的接招時間、敵人被打的硬直                                                                                      |
| 敵人行動         | 移動速度、開火頻率（武器冷卻＋AI 決定開火的機率）、子彈速度、精準度、傷害、衝擊、預警時間、子彈大小、導彈追蹤力、反應速度、失衡門檻、失衡時間 |
| 敵人數量與積極度 | 血量、每波數量、同時進攻台數、壓制時開火率、察覺範圍、增援間隔                                                                                |
| 每一把武器       | 子彈速度、射速、傷害、衝擊                                                                                                                    |

戰場設定：地圖、變體、等級、敵人（依等級的一般編成或指定一種＋台數）、加一台敵對 AC、一出現就交戰、清完自動補、不會被擊破、彈藥無限。另有「部位判定：擦過不算」（`cfg.strict` → `PACE.strict`：人形機甲的命中只看各區塊的外框，docs/hit-react-design.md 的「部位判定」）。
對照用的數字：時間、擊破數、平均擊破時間、每分鐘受到的傷害、命中率、每分鐘 QB、被擊破次數。

## 實作

- `data/pace.js`：參數表 `PACE_GROUPS`、目前的值 `PACE`、`pv(鍵)`、`pk(機體, 我方鍵, 敵方鍵)`、開火用的武器定義 `paceDef`（我方／敵方＋每把武器的倍率，依版本快取）。
- 套用的地方：`MechEntity.fire`（`paceDef`）、`move`（移動、QB、突擊推進、EN、冷卻、無敵）、`riseStart`（跳躍）、`hitStopLocal`（頓格）、近戰（傷害、突進、硬直、接招寬限）、失衡（門檻、時間）、`trackVel` 與轉身（反應速度）、`pqbDodge`（完美 QB）、敵人 AI 的開火機率 `fk`、`mech-moves.js`（預警的準備時間）、`projectile.js`（敵人子彈的判定半徑）、`Game.loop`（遊戲速度）、`spawnEnemy`（血量）、`rollComp`（數量）、`ai-director.js`（攻擊名額、聲音）、`mech-sense.js`（視覺）、`waves.js`（增援間隔）。
- 調整室：`startMission` 看 `this.paceLab` 換成選的地圖、等級與編成（一般大小的地圖、不從邊緣進場、沒有據點）；主迴圈的清除改呼叫 `paceCleared`（2.5 秒後補下一批），`paceTick` 處理無敵、彈藥與統計。
