# 敵人與 Boss 的閃避（2026-11-21 定案）

使用者回報：「不管是敵人或是 Boss 都沒有各種閃躲玩家攻擊的能力與動作」。

## 1. 改版前的狀況

- 敵對 AC、DUELIST、雨型、狙擊型有隨機的側向 QB（`mech-entity.js` 的 updateAI 一般分支）：玩家剛開火或 8 m 內有玩家子彈就有機率閃，方向隨便往側面，不看子彈從哪裡來。
- 一般 MT 明確排除；專屬敵人的 QB 都是拉近距離；Boss 只有刁鑽度 7～8 會躲「打回去的彈」；機獸的側移片段是攻擊招式。
- 衝擊波與環境陷阱的跳躍（`aiJumpT`，45%）、DUELIST 的近戰格擋（55%）。
- 閃避只有 0.16 秒、一個 QB 姿勢，閃避中的 0.14 秒無敵讓子彈直接穿過去、沒有任何提示，看起來像打偏。
- 玩家的命中輔助（預判、彈道修正 `bend`、加大的判定、雷射即時命中）把小幅度的閃避吃掉；甩掉導彈 `missileDodge` 只給玩家。

## 2. 定案

1. **偏動作遊戲**：大部分的敵人都會閃（不是只有 AC、精英、Boss）。
2. **閃完有破綻**：閃避結束後的一小段時間被玩家打中＝CRITICAL，第一下風格評價加「讀招」。
3. **閃開的子彈失去彈道修正**（和玩家甩導彈對稱）；追著它的導彈在最後一刻被閃開時失去追蹤。
4. **設定「敵人的閃避」**（`ctrl.dodge`：關閉／少／標準（預設）／多；多人以房主的為準）。
5. **巨型 Boss 不閃、改成防禦反應**（收起部位、展開護盾、縮殼……），而且要看得出來（專屬的姿勢或光效＋字）。
6. **全做**：一般敵人、步行機、載具、直升機與無人機、約 55 種專屬敵人、8 隻機獸、28 隻 Boss 各自有反應。
7. **擊破時間接受稍微變長**（不為了閃避調血量；量測只確認沒有變成拖很久）。

## 3. 共用的規則（`entities/mech-dodge.js`、數值 `data/dodge.js`）

只在房主／單機計算；客機看快照的 QB 狀態、`aw` 的破綻位元與閃避動作的欄位。

- **威脅判斷**（每 `SCAN` 秒，錯開）：
  - 投射物：敵對陣營的子彈、砲彈、榴彈、導彈，算到達最接近點的時間與最近距離，落在時間窗 `WIN` 裡、會打中（自己的半徑＋餘裕＋爆炸半徑）才算；追著自己的導彈用距離÷速度。
  - 蓄力：鎖定自己的玩家的蓄力射擊快充滿、蓄力雷射快射出時（雷射是即時命中，只能提前閃）。
  - 雷射：剛被雷射打中時，之後有機會閃開讓光束斷掉。
  - 近戰：玩家正對自己出刀、或突擊推進衝向自己。
- **決定**：一次威脅擲一次（失敗後 `REROLL` 秒內不再擲），機率＝種類的基本值 × 技巧 × 設定 × 壓力（玩家吃緊時 ×`STRESS_K`）；反應時間 `REACT`；同一時間全場最多 `CAP`＋人數台開始閃；自己在出招的準備、失衡、被打的硬直、近戰中不閃；還沒察覺玩家（待機、起疑）不閃。
- **方向**：側閃＝和子彈的方向垂直、往子彈軌跡的另一側；避開虛空、作戰區域外、障礙物，兩側都不行時往後；近戰改往後或側。
- **看得出來**：反應時間裡推進器先亮一下（預兆）；閃避的 QB 比一般 QB 長（`QB_T`）、加揚塵與殘影；頭上跳「閃避」。
- **破綻**：閃完 `OPEN` 秒＝弱點露出（`wpOpen`，快照的 aw 32），玩家打中是 CRITICAL；Boss 的破綻是傷害 ×`OPEN_K_BOSS`；第一下風格評價「讀招」。
- **冷卻**：每種各自的冷卻＋QB 的 EN。

## 4. 各類的閃避（分期）

| 期  | 對象                                        | 閃避與反應                                                                                             |
| --- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 1   | 人形的一般敵人（MT、步行機、敵對 AC、精英） | 共用的規則全部＋側閃、後撤、跳躍閃避；破綻、讀招、提示、彈道修正失效、導彈甩脫、設定                   |
| 2   | 人形機甲的新動作                            | 地面翻滾、滑鏟、空中翻滾、後空翻；敵人的殘影；快照同步（`NET_VERSION`）                                |
| 3   | 載具、直升機、無人機、砲台類                | 急轉、倒車、急升降、橫滾；熱焰彈（甩導彈）、煙幕彈                                                     |
| 4   | 專屬敵人（約 55 種，依章節分批）            | 依特性的反應：潛航、鑽地、隱形、埋雪、縮殼、浮起、閃到平台下……                                         |
| 5   | 機獸 8 隻                                   | 野獸式的側跳、後跳、伏低（純閃避的片段），閃完可以接反撲                                               |
| 6   | Boss 28 隻                                  | 機甲型連續閃避；巨型改防禦反應（專屬姿勢或光效＋「防禦」字）；依刁鑽度讀蓄力射擊、甩導彈；量測擊破時間 |

每期做完：lint、format、build、相關的冒煙測試步驟（`testAiDodge` 等），提交並推送。

## 5. 實作紀錄

### 第 1 期（2026-11-21）：共用的規則＋人形的一般敵人

- `data/dodge.js`：`DG`（時間窗、反應時間、閃避的 QB 0.26 秒與無敵 0.18 秒、破綻 0.55 秒、全場上限、壓力、近戰與雷射的倍率、設定的倍率）、`DG_CLASS`（ace／mt／heavy／quad／fly 的機率、冷卻、會的閃避）。
- `entities/mech-dodge.js`（`main.js` 載入）：
  - `dgClass` 決定種類：人形（`buildMech`、沒有 `modelKind`）、不是 Boss、專屬敵人、支援類；這一期以外的回傳 null。
  - `dgOn`：房主／單機、不是玩家操作、空域、過場、靶場、教學、實驗室、PvP。
  - `dgMove`（`move()` 開頭呼叫，改 wish／按住跳／QB）：掃描 → 擲 → 反應時間（推進器的預兆 `boostFlame`）→ `dgStart`（種類、方向 `dgSafe`、彈道修正與導彈）→ 閃避中 → 破綻。
  - `dgThreat`：投射物的最接近點；追著自己的導彈只在最後 `MSL_LAST`＋反應時間內才算（太早閃導彈會轉回來）；鎖定自己的玩家蓄力快滿（`pwCh`、`charging`）；剛被雷射打中（`dgLaserT`，`takeDamage` 記）；近戰出刀、突擊推進衝過來。
  - `dgQbStart`（`move` 的 QB 開始）：閃避的 QB 拉長、無敵拉長、揚塵。
  - `dgAbsorb`（`takeDamage` 的無敵分支）與 `dgStart`：頭上「閃避」字（`popDamage`，房主轉送）。
  - `dgHit`（`takeDamage`）：破綻中第一下「讀招」（`SY_EV.read`）；Boss 與近戰的破綻 ×`OPEN_K_BOSS`；遠程的 CRITICAL 走 `wpOpen`（`mech-weak.js` 先看 `dg.open`），客機看 `senseAw` 的 32。
- 舊的隨機閃避（一般分支、DUELIST、雨型）在有 `dgClass` 時不再看附近的子彈（隨機的換位 QB 保留）。
- 設定「敵人的閃避」`ctrl.dodge`：遊戲與進階的「遊戲」、快速設定的常用項目、客機停用。
- 冒煙測試 `testAiDodge`（`g.dgForce`＝直接指定機率）；測試環境的預設 `dodge: 'off'`（舊的測試假設敵人不閃）。

### 第 2 期（2026-11-21）：人形機甲的閃避動作、殘影、同步

- 閃避的動作（`data/dodge.js` 的 `DG_ANIM`，人形的二足／逆關節）：`cart` 地面側翻、`slide` 滑鏟、`bflip` 後空翻、`aflip` 空中側翻，剩下的機率是只有 QB 的姿勢；敵對 AC 翻得比 MT 多。
- `render/mech-model.js` 的 `animateMech`：`st.evade`（`animExtra` 的 `evade`＝`evadeTake`）一次觸發。翻轉沿用空中跳的繞髖翻轉（`an.flip`），`an.flipGround` 讓它在地面也翻（繞髖轉，頭碰不到地）；滑鏟 `an.slide`（`SLIDE_T`）壓低、往後仰、往滑的方向側傾。
- 翻轉的閃避無敵 `FLIP_IF`（看得到在翻、子彈穿過去）；閃避的殘影 `evadeFx`（`mech-vfx.js` 的 `mvfxTick` 每格，各端；橘紅色，設定「殘影」關閉時不留）。
- 距離：閃避的 QB 和一般 QB 差不多長（敵對 AC 0.15 秒、一般敵人 0.11～0.12 秒，`DG_CLASS` 的 `qb`）；拉長到 0.26 秒會滑 60 m，太遠。
- 同步：房主送 `dgv` 事件（動作、機體座標的前後與左右），客機 `evadeGo`；`NET_VERSION` 11.55。
- 冒煙測試 `testAiDodge` 加上側翻、後空翻（整台翻過去）、滑鏟（不翻）、殘影；`g.dgAnimForce` 指定動作。
