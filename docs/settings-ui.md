# 設定畫面

2026-11-03 使用者定案：設定原本是一整條約 90 項的長頁面（「控制方式」一類就塞了 30 項，一半和操作無關），很難找。
改成 **A＋C**：上方分頁＋下方說明欄（機戰傭兵6 式），第一頁是「快速設定」（兩組一鍵套用的組合＋常用項目），
另外四項改進一起做：說明欄取代滑鼠停留提示、「恢復預設」只重設目前這一頁並先確認、暫停選單的按鈕改名「設定」與
「下次出擊生效」的提示、改過的項目標小圓點。

## 參考的作法

- 機戰傭兵6：上方分頁、手把 LB／RB 換頁，選到的項目在下方顯示說明。
- 決勝時刻（Modern Warfare II／III）：左側分類＋右側說明欄＋搜尋框（搜尋之後可以加在分頁上方，現在不做）。
- 最後生還者 第二部：選項很多時先給預設組合，一鍵套用再細調。

## 分頁

| 分頁 | key | 內容 |
|---|---|---|
| 快速設定 | quick | 畫面品質（效能／平衡／品質）、操作輔助（新手／標準／老手）、常用 8 項 |
| 操作 | ctrl | 射擊（瞄準、按住連射、蓄力、主動裝填、自動攻擊）、移動與近戰（移動方向、近戰輸入輔助、處決）、遊戲節奏 |
| 按鍵 | keys | 鍵盤／滑鼠與手把的按鍵、虛擬手把、手把震動、震動測試 |
| 鏡頭 | cam | 共通（預設視角、靈敏度、上下反轉）、第三人稱俯視（距離、最遠距離、近戰特寫）、追尾視角（距離、視野、速度偏移） |
| 畫面 | gfx | 渲染風格（風格、金屬、解析度、實驗室）、效果（水面、機甲特效、砲火特效、殘影）、動作 IK |
| 介面與演出 | ui | 戰鬥中的文字（傷害數字、狀態字、自己受傷的數字）、演出（文字演出、劇情動畫、整備演出、血跡） |
| 聲音 | snd | 音量 5 項、語音與字幕、戰鬥配樂 |
| 遊戲與進階 | adv | 地圖物件的破壞、眼動追蹤、本地模型庫與伺服器模型組 |

## 實作（`game/settings.js`、`src/index.html` 的 `#settings`）

- **結構**：`#setTabs`（`data-padtabs`，手把 LB／RB）→ `#setBody` 裡每一頁是 `section.setPage[data-st]`（`data-intro`＝沒有選到項目時說明欄的文字）→ `#setDesc` 說明欄 → 返回、恢復這一頁的預設。
  面板固定大小（`min(780px, 96vw) × min(720px, 92vh)`），只有內容捲動；矮螢幕（≤ 540 px）拿掉標題、說明欄縮成兩行。
- **欄位沒有改 id**：各控制項的 `onchange` 照舊在 `input.js` 綁定，所以搬分頁不影響原本的邏輯。`openSettings(from, tab)` 打開時用上次的分頁（`lastTab`，預設快速設定）；`settingsTab(k)` 切換。
- **說明欄**（`setDescFor`）：滑鼠停留（`pointerover`）、鍵盤焦點（`focusin`）、手把焦點（`pad-ui.js` 的 `padUiFocus` 呼叫）時顯示那一列的說明：
  控制項或列的 `title` 第一次碰到時搬進 `data-desc`（不再跳出瀏覽器的提示），沒有 title 的列在 HTML 寫 `data-desc`；都沒有時用勾選框的文字。操作結果（套用組合、恢復預設）用 `setNote` 停留 1.5 秒。
- **預設值與改過的標記**（`setMarks`，`#settings` 的 change 冒泡時更新）：控制項的預設值＝`data-def`，否則是文字含「預設」的選項（所以新增下拉選單時照舊在預設的選項寫「（預設）」就好；勾選框與沒有這個字的要寫 `data-def`）。和預設不同的列加 `.chg`（名稱前的藍色小圓點），分頁按鈕也標。按鍵依 `defaultKeys`／`defaultPad` 比較；本地模型庫不比較。
- **恢復這一頁的預設**（`settingsReset`）：`uiConfirm` 確認後，逐項把和預設不同的控制項設回預設值並觸發 change（走原本的 onchange，所以副作用一致；眼動、IK 的區塊會重新產生，所以每次重新找）。停用的控制項略過（多人客機的遊戲節奏與破壞設定），眼動與 IK 的子項目例外；本地模型庫與眼動的校準結果不動。按鍵頁另外還原 `keymap`／`padmap`；快速設定頁還原兩組組合與常用項目。以前的「恢復預設」會把整個 `ctrl` 清成五個欄位（音量、語音、眼動…全部消失），已拿掉。
- **快速設定**（`renderQuick`）：組合 `PRESETS`（{ 控制項 id: 值 }，寫進原本的控制項再觸發 change；目前符合的組合亮起，都不符合顯示「自訂」）；常用 `QUICK` 複製原本的下拉選單（`data-mirror`＝原本的選擇器），改的時候寫回原本的控制項，所以兩邊一致。
- **任務中**（從暫停選單開，`#settings.inMission`）：2026-11-04 使用者反映「暫停改設定、繼續之後沒有即時套用」，調查後定案「任務中改的設定回到遊戲就生效」（下一節）。列上有 `data-next` 的名稱後面標「（下次出擊生效）」（目前沒有這種項目，機制保留）。

## 任務中改設定

- **全部即時**：大部分設定本來就是使用時才讀 `ctrl`，改了就生效（鏡頭、遊戲節奏、畫面品質、解析度、音量、特效、文字演出、傷害數字、近戰／射擊的輔助、IK、觸控…）；`data-lazy` 的（砲火特效、機甲特效）說明欄補「下一顆子彈、下一個爆炸就換」。
- **回到遊戲時才套用的**（`settings.js` 的 `setTrack` 記下、`settingsApplyMission` 在 `resume` 與多人的「繼續」時做）：預設視角（`setPendView`：直接換成那個視角；空域、訓練課程、觀戰、實驗室不換）、本地模型庫（`setPendLm`：`lmRefresh` 後自己的機體 `swapModel`，只有單人；其他物件下次出擊）、武器欄的按鍵標示（`renderWeaponHud(true)`）。`clearMission` 清掉這些紀錄。
- **渲染風格與機體金屬**：任務中也能換（`styleRefresh`；色調映射或陰影種類不同時全部材質重新編譯，會頓一下，`#styleNote` 說明）；渲染風格實驗室的按鈕照舊停用。
- **提示**：改過的項目名稱（列的第一個 span，IK／眼動／本地模型庫用總稱、超過 14 字截斷）在回到遊戲時以 `flashMsg`「已套用設定 — 前 4 項 等 n 項」顯示；沒改不提示。
- **多人**：`data-host` 的（遊戲節奏、地圖物件的破壞）以房主為準：客機的設定畫面停用並標「（以房主為準）」（`#settings.mpClient`），說明欄補一句；房主在任務中改遊戲節奏時快照的 `mis.pc` 帶給客機（`hostPace`，以前只在開局送一次，`NET_VERSION` 11.23），破壞設定本來就在快照的 `mis.dm`。
- 遠程訓練課程的某一步暫時換了蓄力方式時，課程中在設定改的蓄力方式會在課程結束時保留（`tutChargePrev` 跟著改）。
- **新增設定項目**：放進對應分頁的 `section`（必要時加 `h4` 小標），在 `renderSettings` 設定值、`input.js` 綁 onchange；寫說明（`title` 或 `data-desc`）與預設值（「（預設）」或 `data-def`）；常用的可以加進 `QUICK`。
